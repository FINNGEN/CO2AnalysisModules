## Cohort Demographics

Cohort Demographics summarises basic characteristics of the selected cohorts. Use it to check whether the cohorts differ in size, age, sex, or other available demographic variables before interpreting an association analysis.

### How to use the viewer

Select one or more cohorts and set the minimum cell count. Review the displayed counts and distributions, paying attention to small groups and missing values. These summaries describe the cohorts; they are not an adjustment for confounding.
