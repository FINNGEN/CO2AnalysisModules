## Cohort Overlaps

Cohort Overlaps shows how people are shared between the selected cohorts. The main plot displays intersections: each combination represents the people present in those cohorts, and the set sizes show the total size of each cohort.

### How to use the viewer

Select the cohorts to include, then use the plot controls to show or hide intersection sizes and cohort sizes. Use the minimum cell count to hide very small intersections when the plot is difficult to read.

An overlap is descriptive. It does not by itself indicate that one cohort causes another or that the cohorts are clinically equivalent.
