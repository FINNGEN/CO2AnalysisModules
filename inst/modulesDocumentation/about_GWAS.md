## GWAS

GWAS submits a genetic association analysis using the selected case and control cohorts and the configured analysis type.

Before submitting, verify the case and control cohorts, the analysis type, and any optional follow-up setting. The run is submitted to the configured workflow and may take time to complete. Use the workflow status and the resulting viewer or downloaded results to inspect the analysis.

The result is an association analysis. It requires appropriate cohort definitions, quality control, and interpretation outside this screen.
