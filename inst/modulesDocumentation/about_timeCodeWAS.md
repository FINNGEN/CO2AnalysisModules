## Time Code WAS

Time Code WAS compares selected clinical features between a case cohort and a control cohort in a series of time windows around each person's cohort start date. It is for asking when a feature is enriched: before, at, or after the cohort index date.

### Before running

- Select the case and control cohorts, or choose automatic controls when that option is available.
- Select the clinical feature groups to compare and set the minimum cell count.
- Define time-window breakpoints in days, months, or years. Negative values create windows before cohort start; positive values create windows after it. The displayed windows do not overlap.

### Interpreting results

Each result is tied to a specific time window. Compare the effect, number of people observed in that window, and statistical significance across windows before interpreting a pattern.

A timing pattern can reflect the clinical course of a condition, but it can also reflect cohort construction, differences in observation time, healthcare use, or recording practice. Check the concept definition and the underlying counts before drawing a conclusion.
